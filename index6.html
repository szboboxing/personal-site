鼠标Pro MousePro

v1.0.1 2026-10-08

基于开源 PourInput 独立演进的全能鼠标增强：每个按键单击/长按双映射、按应用自动切换，再叠加右键手势与系统工具箱。

  • ·侧键只在浏览器有用，换个软件就闲置或误触

  • ·想给不同软件配不同鼠标动作，系统做不到

  • ▸每键单击/长按两套动作，按应用自动切换配置
  • ▸右键+滚轮/侧键：复制、增强粘贴、截图
  • ▸系统工具：指针大小（Win10/11）、亮度对比度、计算器
[1]按键映射：每键单击/长按两套动作，按应用自动切换
[2]右键组合手势：复制、增强粘贴、截图
[3]系统工具箱：指针大小（Win10/11）、亮度对比度、计算器
[4]基于开源 PourInput 独立演进，默认简体中文

物业管理台账 HTML 单文件版

v1.4 2026-10-14

把 Blazor 物业管理台账重构成纯前端：两个 HTML 文件，双击即用，不装 Docker 不装数据库，PC / 手机 / 平板浏览器全兼容。

// PAIN 痛点

  • ·服务器版要装 Docker 容器 + PostgreSQL 数据库，手机访问还要搭公网
  • ·换电脑换环境，备份迁移要搬数据卷
  • ·房东自己电脑就能记账，但常驻容器太重

  • ▸IndexedDB 本地存储 + 数据文件绑定（Chrome/Edge）防清缓存
  • ▸业务语义对齐 v2.4：月付/季付出账、改租约自动重算、浅色主题、批量结清、账单图

    关于我

    独立开发者，主力在 Windows 平台做实用小工具。白天和表格、文件名、COM 自动化打交道， 晚上维护六个开源项目。相信工具应该解决具体问题，而不是炫技。

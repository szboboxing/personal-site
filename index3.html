鼠标Pro MousePro

  • · 想给不同软件配不同鼠标动作，系统做不到

  • ▸ 右键+滚轮/侧键：复制、增强粘贴、截图
  • ▸ 系统工具：指针大小（Win10/11）、亮度对比度、计算器

  • ▸ 欠款一览按租客分页列出逾期，中文账单图含收款码，可批量结清

06

物业管理台账 HTML 单文件版

v1.4 2026-10-14

把 Blazor 物业管理台账重构成纯前端：两个 HTML 文件，双击即用，不装 Docker 不装数据库，PC / 手机 / 平板浏览器全兼容。

PAIN

  • · 服务器版要装 Docker + PostgreSQL，换电脑迁移要搬数据卷，手机访问还要搭公网
  • · 换电脑换环境，备份迁移要搬数据卷
  • · 房东自己电脑就能记账，但常驻 Docker 容器太重

FIX

  • ▸ 两文件备份 U 盘随身：物业管理台账.html + 使用说明.html
  • ▸ IndexedDB 本地存储 + 数据文件绑定（Chrome/Edge）防清缓存
  • ▸ 业务语义对齐 v2.4：月付/季付出账、改租约自动重算、浅色主题、批量结清、账单图
纯 HTML IndexedDB Vanilla JS PBKDF2 File System Access

物业管理台账 PHP 版

v1.0 2026-10-16

把台账搬上免费虚拟主机：5 个文件 FTP 上传，网页向导 30 秒装好；PHP + MySQL，手机电脑打开网页就能记账催租。

PAIN

  • · HTML 单机版数据锁在浏览器，出门用手机查不了账
  • · Docker 版要常驻机器，装环境配数据库自己搞不定
  • · 买服务器一年几百块，只为记账太不划算

FIX

  • ▸ 原生 PHP 8 + MySQL，无框架无依赖，免费虚拟主机直接跑
  • ▸ 网页向导自动测连接、建 10 张表、建管理员，30 秒上线
  • ▸ 自动出账 / 改租智能重算 / bcrypt 登录 / JSON 快照，前端整套移植
PHP 8 MySQL 无依赖 REST API bcrypt

    关于我

    独立开发者，主力在 Windows 平台做实用小工具。白天和表格、文件名、COM 自动化打交道， 晚上维护七个开源项目。相信工具应该解决具体问题，而不是炫技。

    这些项目都来自我自己的工作流：批量重命名是受够了手动改文件夹， 规约上传是 WPS 表格比对太费眼，鼠标手势是想让复制粘贴截图不用满屏找按钮。 鼠标Pro 则在开源 PourInput 基础上做全能增强，把按键映射、手势和系统工具收进一个面板； 物业管理台账来自真实房东的手工 Excel 对账——每月翻表算欠款太痛，就写了套自动出账的系统。 自己用顺手了，就开源出来。
